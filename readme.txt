#Genomic Trait Prediction Using Linear Regression

##Project Summary

In this project, I created a simulated genomic dataset to study how genetic markers influence a quantitative trait.

The dataset contains 500 records with five genetic markers and one target variable (Trait). The goal was to predict the trait value using Linear Regression and identify which markers have the strongest impact.

The data is simulated but follows a realistic statistical relationship between genetic markers and trait values.

---

##Work Done

* Generated a dataset containing 500 samples
* Loaded and analyzed data using Python
* Performed Exploratory Data Analysis (EDA)
* Checked descriptive statistics and missing values
* Created a correlation matrix and heatmap
* Split the dataset into training and testing sets
* Built an OLS Linear Regression model using StatsModels
* Identified significant predictors using p-values
* Performed feature selection
* Compared actual and predicted values using visualization

---

##Key Observations

* Some genetic markers showed a strong relationship with the target trait
* Correlation analysis helped identify important predictors
* The regression model successfully predicted trait values
* Significant markers contributed more to prediction accuracy
* Feature selection simplified the model without affecting performance

---

##Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn, StatsModels, Scikit-Learn, Jupyter Notebook

---

##Conclusion

This project demonstrates how Linear Regression can be used to predict a quantitative trait from genetic marker data.

The analysis helped identify statistically significant markers and showed that predictive modeling can be applied effectively to genomic datasets.

The project also provided practical experience in data analysis, visualization, feature selection, and statistical modeling.
